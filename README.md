### 1. Sensor Fault Controller

**C11 · Finite-State Machines · Unit Testing · WebAssembly**

A modular C controller that models temperature monitoring, sensor faults, and recovery through a finite-state machine.

- Implemented NORMAL, WARNING, and FAULT states with threshold-based transitions.
- Added sensor-error handling, fault latching, and recovery logic.

### 2. Firmware Validation Framework

**Python · C · Test Automation · JSON Reporting**

A Python framework that executes a compiled C controller and evaluates its actual behavior against expected results.

- Automated controller execution and checks for exit status, state, fault code, and temperature.
- Implemented timeout handling, failure detection, and repeatable test execution.
- Generated structured JSON reports for validation and debugging.
- Built an interactive dashboard for running tests and reviewing results.
