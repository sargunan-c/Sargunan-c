## 🚀 Featured Projects

### 1. Sensor Fault Controller

**C11 · Finite-State Machine · Unit Testing · WebAssembly**

A modular C controller that models temperature monitoring, sensor errors, fault handling, and recovery using a finite-state machine.

- Implemented NORMAL, WARNING, and FAULT states with temperature-threshold handling.
- Added sensor-error detection, fault latching, and recovery logic.
- Tested threshold boundaries, invalid inputs, sensor faults, and recovery scenarios.
- Compiled the controller to WebAssembly to run an interactive browser-based demonstration using simulated inputs.

**Validation:** 31/31 native C scenarios and 31/31 WebAssembly scenarios passing, according to the project test results.

### 2. Firmware Validation Framework

**Python · C · Test Automation · JSON Reporting**

A Python-based validation framework that executes a compiled C controller and compares actual results with expected behavior.

- Automated checks for exit status, controller state, fault code, and temperature.
- Implemented test execution, timeout handling, and failure reporting.
- Created structured JSON reports for repeatable validation and debugging.
- Built an interactive dashboard to run validation suites and review results.

**Validation:** The project reports 37 controller test cases and 16 framework unit tests passing. These are separate test suites from Project 1.
